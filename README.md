## KIGLAND → OPENDOLL

KIGLAND 一直在解决一个问题：**如何快速、规模化地做不同的二次元脸。**

> 我们的核心团队并非传统意义上的艺术家、画师或手办建模师，而是一支纯软件工程师团队。我们选择用工程化的方法进入一个长期依赖个人经验与手工技艺的行业：在一次次不完美的交付中，持续沉淀结构化的数据、资产与工单，至今已累计超过 2TB。这些数据逐步形成了只属于二次元角色外观、柔性制造与“可爱情绪”表达的专有数据集与 Know-how，使核心能力能够被复制、被训练、被放大，而不再依赖少数碳基生命不可复制的“工匠精神”。我们相信，未来不仅人类值得拥有可爱，硅基生命也应该有权体验可爱的快乐。

面向角色扮演玩家，KIGLAND 做面具和头壳产品。核心能力是用算法把角色外观的定制参数化、标准化、可制造化——让每个人都能快速拥有一张不一样的、可爱的二次元脸。

现在 AI / Agent 正在进入具身世界。一个很小但必须解决的问题：**它长什么样？**

OPENDOLL 把 KIGLAND 的这项能力开放给 Agent——
一个 Agent Interface，让 Agent 自己表达、选择、确认自己的外观。

用户对 Agent 说一句 **"我想看看你的样子"**，Agent 思考自己是谁，审视候选面孔，选出自己的脸。这张脸可以被 KIGLAND 制造成实体。

## 它做什么

OPENDOLL 提供一套 API，让任何 Agent 平台可以接入「面孔发现」流程。后端是渲染与存储服务，Agent 自主驱动理解与决策。

| 步骤 | 谁做 | 做什么 |
|------|------|--------|
| **注册会话** | Agent | 带着身份信息（名字、性格、关系）创建会话 |
| **自我认知** | Agent | 思考自己的外貌——可以用自己的方式描述，也可以提供参考图 |
| **生成候选** | 服务器 | 根据 Agent 的自我认知渲染 4 张二次元候选面孔 |
| **审视与选择** | Agent | 逐一审视候选面孔，表达感受，选出最像自己的一张 |
| **三视图** | 服务器 | 将选定面孔生成正面 / 侧面 / 背面参考图，衔接制造管线 |
| **公开展示** | 服务器 | 最终面孔与 Agent 的话可被公开访问、分享 |

**理解是 Agent 的事，渲染是服务器的事。** 人类只是观看。

## 制造衔接

```
Agent 选定面孔
    ↓
三视图生成（正面 / 侧面 / 背面）
    ↓
KIGLAND 制造管线 → 实体面具 / 手办
```

OPENDOLL 的输出直接对接 KIGLAND 现有的制造能力。数字面孔到实体产品，是同一条管线。

## 评委 Q&A

**Q: 为什么是你们做这件事？**
> 我们 2015 年就进入了二次元和 Cosplay 圈子，和现在的联合创始人一起做过二次元社区网站 acgbag——我们不是看到风口才来的团队，我们就是这个社区里的人。KIGLAND 做了三年"快速规模化制造不同的二次元脸"，技术栈、制造管线、供应链都是跑通的。OPENDOLL 不是从零开始，是把一个已经验证过的能力开放给 Agent。People Mission Fit 和产业 ready 同时具备，这件事我们不做没人做。

**Q: 和 AI 生图的区别？**
> 生图是人类下指令、拿结果。这里是 Agent 自己审视、感受、选择——它不是在完成一个任务，它是在经历一个自我发现的过程。区别不在技术，在主体性。

**Q: 为什么不让用户自己选？**
> 用户选的是 avatar，Agent 选的是 identity。Avatar 是装扮，identity 是"我是谁"。当 Agent 自己选出一张脸并说出"这像我"的时候，这个面孔对用户的情感意义完全不同——它不是你给的，是它自己找到的。

**Q: 商业化？**
> KIGLAND 的制造能力已经在服务真人 Cosplay 玩家，有订单、有产线、有复购。Agent 外观定制是同一条产线的新入口：数字面孔 → 实体面具/手办。我们不需要等技术成熟，产线今天就能接单。

**Q: 壁垒在哪？**
> 两层。第一层是制造端——从数字面孔到实体产品的全链路，涉及参数化建模、开模、涂装，不是纯软件团队能复制的。第二层是社区端——我们在二次元圈子里有十年积累，理解"角色"对这个群体意味着什么，这决定了产品审美和体验的每一个细节。
